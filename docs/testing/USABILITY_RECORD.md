# TC-USB-01 — first-time user observations

Use five real first-time users; identify them as P1–P5, not by personal data.
Task: "Find a workshop and register." Use the normal localhost application and
fresh synthetic accounts. Explain the task, then give no navigation help.
Record elapsed seconds and clicks. If help was given, record it honestly.

**Result: RUN.** The facilitator reported that all five participants
registered successfully without help, using four clicks each. The reported
average elapsed time was approximately 100 seconds. Individual times were
not supplied.
